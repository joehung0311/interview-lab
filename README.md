## 1. 專案介紹

**適合台灣一般求職者使用的 AI 智慧面試準備工具。**

適用對象包括社會新鮮人、一般上班族、跨產業或跨職能轉職者、二度就業及職場重返者、中高齡求職者、技術與工程人員、行政與服務業人員、專業證照工作者、管理職求職者，以及實習和兼職求職者。

AI 是幫你準備面試的工具，**不代表你一定要應徵 AI 相關職務**。

這是一個面試準備提示詞產生器：一步一步帶使用者整理公司、職缺和自己的資料，產生完整的提示詞交給 ChatGPT、Claude 或 Gemini 執行，再把 AI 的分析結果貼回來，整理成「私人準備版」、「面試官展示版」和「面試圖表」的繪圖提示詞。

**這個工具不會**自己上網查公司、不會自動呼叫 AI、不會替使用者編經歷或回答面試。目的是幫使用者建立自己的分析與思考能力。

> 設計原則：不論使用者的產業、年齡、工作經驗或是否熟悉 AI，都能透過簡單的操作完成適合自己的面試準備。

## 2. 核心功能

- **六步驟流程**：公司或機構 → 職缺 → 個人能力 → 顧問團 → 成果 → 生成與匯出
- **快速模式／完整模式**：共用同一套功能，只差在顯示的欄位與預設勾選
- **通用分類**（V1.0.2）：19 種產業、10 種組織型態、20 種職務分類、8 種工作型態、分組的面試情境、10 種求職情境
- **分類式技能選擇器**（V1.0.2）：18 類技能、關鍵字搜尋、跨分類複選、履歷技能快速貼上、自動去重、自訂技能、熟練程度（選填）、依職務推薦
- **8 位模擬顧問角色**：三種預設組合（快速 4 位、一般完整 6 位、全部 8 位），品牌策略師與 AI 應用規劃師只在相關職務時建議加入
- **分析模組 A–G**，每個模組的設定都會真正影響提示詞：
  - A 企業與組織公開資訊研究
  - B 企業商業模式與營運觀察（Lean Canvas、BMC、一般觀察、服務流程與組織使命）
  - C 職務應用與價值提案（13 種主題，AI 只是其中一種，也可以不提案）
  - D 個人職務適配分析
  - E 模擬面試（依職務與情境調整，STAR 適用時才用）
  - F 到職學習與工作計畫（一般、30／60／90 天、第一週／第一個月、實習或兼職、自訂期間）
  - G 面試圖表（可只做一張、兩張或三張，標題依設定變化）
- **提示詞過期提醒**：資料或設定改了就提醒重新生成，避免複製到舊公司、舊職缺的提示詞
- **兩種輸出版本**：私人準備版（內容可自選）、面試官展示版（需完成確認清單才能使用）
- **匯出**：提示詞 TXT／Markdown、兩個版本各自的 TXT／Markdown、專案 JSON 匯出與匯入
- **六組跨產業虛構示範案例**，附虛構的示範 AI 回覆
- 專有名詞（JD、Lean Canvas、BMC、STAR、可轉移技能、虛擬顧問團等）都附白話說明與使用限制

## 3. 使用方式

| 步驟 | 要做的事 |
|---|---|
| 首頁 | 選「快速模式」或「完整模式」，或從下拉選單載入示範案例 |
| STEP 01 認識應徵公司或機構 | 名稱、產業、組織型態、官網等（標示「建議填寫」的欄位能讓分析更準，其他可略過） |
| STEP 02 認識應徵職缺 | 職稱、職務分類、工作型態、完整 JD（可整段貼上）、面試情境 |
| STEP 03 個人能力檔案 | 求職情境、過往經歷、技能（貼上或分類選擇）、優勢、證照與其他佐證 |
| STEP 04 AI 虛擬顧問團 | 選角色或套用預設組合；相關職務會出現加入建議 |
| STEP 05 面試準備成果 | 選輸出版本、私人版內容、分析模組，以及各模組的細項設定 |
| STEP 06 生成與匯出 | 第一階段產生提示詞 → 交給外部 AI → 第二階段貼回結果 → 確認兩個版本 → 匯出 |

返回上一步或切換模式時，已填寫的內容都會保留。

### 產業與職務是分開的

「產業」是公司做哪一行，「職務」是你要做的工作。製造業公司也會招募會計、行政或業務，所以技能建議、面試題目和到職計畫都**以職務分類與 JD 為準**，不只看公司產業。

產業與職務分類是參考台灣常見求職平台用語自行整理，**不是任何求職平台的官方分類，也沒有合作關係**。

### 組織型態

選擇「公家機關、學校或教育機構、醫療機構、非營利組織」時，分析會著重組織使命、服務對象與職務價值，模組 B 自動改用「服務流程與組織使命分析」，**不會強迫套用獲利模式**。

### 技能怎麼填

| 方式 | 說明 |
|---|---|
| 快速貼上 | 從自己的履歷複製技能那一段貼上，支援頓號、逗號、分號、換行、直線與項目符號。會自動去除空白和重複（含全形／半形、大小寫），確認後才加入。本工具不會連線到任何求職平台、不需要登入。 |
| 依分類選擇 | 18 個分類切換、關鍵字搜尋、跨分類複選；同一個技能在不同分類都會顯示已選。完整模式預設展開，快速模式收起。 |
| 職務推薦 | 依 STEP 02 的職務分類、職稱與 JD 關鍵字推薦。**只代表職缺可能需要，不代表你已具備**，要自己點選才會加入。 |
| 自訂技能 | 清單沒有的技能可以自己新增，重複的不會加入。 |
| 熟練程度（選填） | 基礎了解、學習中、可獨立操作、具實務經驗、熟練／可指導他人；語言另有基礎、日常溝通、商務應用、精通。**沒填的，提示詞會要求 AI 不得自行判定程度。** |

技能會依類型整理成「擅長工具與軟體、專業工作技能、通用職場能力、語言能力、正在學習的技能、其他自訂技能」，再加上證照、作品集與其他佐證，分開寫進提示詞。涉及專業資格的職務（例如醫療照護），勾選技能不代表具備執業資格。

作品集是選填。沒有作品集時，提示詞會要求 AI 不要要求作品連結，改用工作成果說明、實習、專題、志工或證照等方式佐證。

求職情境會調整「求職／應徵動機」欄位的提示，而且**不需要說明家庭、健康或離職細節**，也不需要填年齡或出生日期。

## 4. 快速模式與完整模式

| | 快速模式 | 完整模式 |
|---|---|---|
| 適合 | 時間有限、很快就要面試 | 想深入研究組織、製作客製化面試資料 |
| 選填欄位與技能分類選擇 | 收起（可展開） | 全部展開 |
| 預設顧問 | 人資招募顧問、部門主管、職涯教練、反方審查員 | 再加產業研究員、商業分析師（共 6 位） |
| 預設模組 | A、D、E | A–G |
| 預設輸出 | 私人準備版 | 私人準備版＋面試官展示版 |

隨時可以切換，切換時不會改動已經填寫或勾選的內容。

## 5. 兩階段 AI 分析流程

**為什麼要分兩階段？** 工具本身沒有組織的資料，不能憑空畫出「某公司的營運圖」。所以先讓外部 AI 做研究，確認過結果之後才做成圖表。

### 第一階段：產生分析提示詞

1. 按「產生提示詞」（可選「全部模組」或「只有某個模組」）。
2. 按「複製並開啟 ChatGPT／Claude／Gemini」：會先複製提示詞，再開新分頁，到對話框貼上送出。
3. 開啟外部 AI 前，畫面會提醒不要貼企業機密、客戶個資或敏感個人資料。

提示詞固定包含 10 條規則：台灣繁體中文、優先官方來源、標示來源網址與日期、區分【已查證】【合理推測】【待確認】【改善構想】、無法上網時必須說明、不捏造公司或機構資訊與財務數字、不捏造求職者經歷也不自行判定技能程度、構想須考慮成本／可行性／資料安全／人工監督且只在指定主題內提出、反方審查、語氣專業謙遜且不超出資格與權限。最後必須提供：建議向面試官確認的問題、分析限制、資料來源、下一步行動建議。

提示詞也會依設定加入「分析時的注意事項」，例如：未標示程度的技能不得判定、沒有作品集時不要求作品連結、使命導向組織不套用獲利模式、實習／兼職／新鮮人不提出組織改革、專業資格領域不得超越資格與權限。

**沒有勾選的模組，提示詞就不會要求 AI 產出那部分**；只選一張圖，AI 也只會被要求產生那一張的素材。

**過期提醒**：產生提示詞後，只要修改公司、職缺、個人資料（含技能與程度）、顧問、模組、模組設定、輸出版本或生成範圍，就會提示「資料已更新，請重新生成提示詞。」。這時按複製、開啟 AI 或匯出，都會先詢問是否重新產生。

### 第二階段：貼回 AI 回覆

提示詞要求 AI 在回覆最後，用固定標記輸出本次需要的區塊：

```
【私人準備版】
【面試官展示版】
【圖一素材】
【圖二素材】
【圖三素材】
【區塊結束】
```

（只會要求 STEP 05 選擇的版本和圖表。）

按「辨識 AI 回覆並填入」後：

- 找到的區塊會放進「私人準備版」、「面試官展示版」和對應的圖表編輯區。
- **缺少的標記**（以本次設定需要的區塊為準）會清楚列出，對應編輯區會清空，避免殘留上一筆資料；提示訊息會顯示「辨識到 X／Y 個需要的區塊」，不會假裝成功。
- **會被取代或清空的既有內容**（包含你手動修改過的）會先列出，按「取代」才執行。
- 分析結果來自另一家公司時（和 STEP 01 名稱不同）會顯示警示。
- 有疑慮的解析結果會列出原因，展示版維持「尚未確認」。
- 完全找不到標記時，內容不會被修改，可以手動貼進各編輯區。

### 兩種輸出版本

| | A｜私人準備版 | B｜面試官展示版 |
|---|---|---|
| 給誰看 | 只給自己 | 面試官（展示或列印） |
| 內容 | 在 STEP 05 自選：企業潛在風險、能力不足與補強方向、可能遇到的困難、薪資談判準備、要向企業確認的問題、模擬面試問題與回答建議 | 依選擇的模組：組織營運初步觀察（B）、職務應用與價值提案或工作理解（C）、個人能力與職務貢獻（D）、到職學習與工作計畫（F），可附面試圖表素材 |
| 預覽、編輯 | ✓ | ✓（列印前預覽） |
| 複製／下載 TXT、Markdown／列印 | 直接使用 | **完成 6 項確認清單後**才能使用 |

展示版確認清單：公司名稱及職缺正確、沒有私人準備內容、沒有未經查證就寫成事實的資訊、沒有錯字或錯誤數據、沒有不必要的個人資料、推測都寫成「初步觀察／待確認」。預覽中的自動檢查只是提醒，最後由使用者判斷；確認之後再修改內容，需要重新確認。展示版預設附註：「本資料依企業公開資訊整理，屬初步觀察與應用構想，實際情況仍須與企業確認。」

## 6. 面試圖表使用說明

三張圖可以個別選擇（STEP 05 模組 G），只做一張、兩張或全部都可以。標題與內容會依設定自動調整：

| 圖 | 標題 | 內容 | 依設定的變化 |
|---|---|---|---|
| 圖一 | 企業與職務觀察圖 | 組織定位、產品及服務、服務對象、營運或服務模式、應徵職務的角色 | 模組 B 選 Lean Canvas／BMC 時用九宮格版面；使命導向組織改為使命與服務流程版面 |
| 圖二 | 依模組 C 主題，例如「行政工作流程圖」「顧客服務流程圖」「品質管理構想圖」「業務開發策略圖」「品牌行銷提案圖」「AI 應用構想圖」 | 工作情境、可能做法、執行步驟、預期效益、注意事項（AI 主題另含資料安全與人工監督） | 沒選模組 C 或選「不需要提案」時，改為「職務需求與工作理解圖」 |
| 圖三 | 我的能力與職務貢獻圖 | 個人經驗、已具備能力、職務需求對照、可提供的職務價值 | 選了模組 F 時加上到職學習構想 |

操作：

1. 第二階段辨識後，素材會進入各自的編輯區；也可以手動貼上，圖三可以「用我的個人檔案預填」。
2. 檢查、修改或刪除內容後，按「產生已選圖表的提示詞」或「只產生圖一／二／三」。
3. 修改某張圖的素材，只有那張會標示需要重新產生；修改風格、尺寸、或會改變圖表標題的設定（例如模組 C 的主題），相關的圖都會標示。
4. 素材是空的圖不會產生提示詞。

每張圖的提示詞分成**視覺版面描述**和**圖上文字清單**。預設是「留白底圖」：要求繪圖 AI 不畫字，之後自己在 Canva 或簡報軟體放上文字，避免中文字畫錯。風格有 7 種（預設專業商務簡報風），尺寸有 6 種（預設 A4 橫式）。

## 7. GitHub Pages 部署方式

### 檔案結構

```
interview-lab/
├── index.html   # 頁面結構（首頁＋六步驟）
├── style.css    # 樣式（深海藍／奶油白／芥末黃／復古紅，含 RWD 與列印樣式）
├── data.js      # 選項與示範資料：產業、組織型態、職務、技能、情境、主題、示範案例（V1.0.2 新增）
├── app.js       # 所有功能邏輯
└── README.md    # 本文件
```

日後要增修產業、職務、技能或示範案例，只需要改 `data.js`。不需要建置工具、套件或後端。

### 部署步驟

1. 在 GitHub 建立新的 repository：`joehung0311/interview-lab`，設為 Public。
2. 把 ZIP 解壓縮後的**五個檔案**上傳到 repository 的**根目錄**（`index.html` 必須在最外層）。
3. 進入 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等 1～3 分鐘，打開 https://joehung0311.github.io/interview-lab/

### 版本管理與快取

- 版本號必須同步修改：`app.js` 的 `APP_VERSION`、`index.html` 的 `style.css?v=`／`data.js?v=`／`app.js?v=` 與頁尾版本號、`style.css` 與 `data.js` 第一行註解、本 README。
- `?v=` 參數用來避免 GitHub Pages 更新後瀏覽器讀到舊的快取檔案。
- 資料格式有變更時，`app.js` 的 `DATA_VERSION` 加 1，並在 `migrate()` 加上舊格式的轉換，**不得直接丟棄舊資料**。
- 版本號規則：修正 → 第三碼 +1；新增功能 → 第二碼 +1。每次修改都在「版本更新紀錄」新增一筆，舊紀錄保留。

## 8. 個人資料與安全說明

- 不需要登入，不需要個人 API Key。
- 不要求身分證字號、生日、地址、電話、年齡；求職動機不需要說明家庭、健康或離職細節。
- 使用者的輸入**不會**被傳送到任何後端伺服器；所有處理都在瀏覽器內完成。
- 技能貼上功能只整理你貼上的文字，**不會**連線或抓取任何求職平台的履歷，也不串接任何 API。
- 本機儲存（LocalStorage）**預設關閉**，按「同意並開啟」後才啟用；關閉時刪除已保存的資料。
- 「清除所有資料」會同時清空畫面與本機儲存。
- 匯出 JSON 前提醒：檔案可能包含個人工作經歷。
- 開啟外部 AI 前提醒：不要提交企業機密、客戶個資或敏感個人資料。
- **重要**：本工具不會主動上傳資料，不代表貼到外部 AI 後也一樣。資料在 ChatGPT、Claude、Gemini 上如何被儲存或使用，由各平台的隱私政策決定。
- 所有使用者輸入、匯入資料與 AI 回覆都以純文字處理（`textContent`／`value`），不會被當成 HTML 或程式碼執行。
- 匯入 JSON 時會檢查檔案來源、限制大小（2 MB），舊格式先轉換，再過濾不在選項清單中的值。
- 所有分析提示詞都要求 AI：不捏造公司資訊、財務數據、個人經歷與技能程度；區分已查證事實、推測、待確認與建議；不假裝已完成研究；不把未驗證的構想描述為組織現有問題。

## 9. 已知限制

1. **分類與技能清單無法涵蓋所有職業**：清單是常見項目，不夠時請用「其他產業」「其他」職務分類與自訂技能。分類為自行整理，可能和各求職平台的分法不同。
2. **技能推薦是關鍵字比對**：依職務分類和 JD 中出現的技能名稱推薦，可能漏掉用其他說法描述的技能，也可能推薦不完全相關的項目。推薦只供參考。
3. **技能自動歸類有限**：貼上的文字若不在清單中（例如「客戶服務」與清單的「顧客服務」用詞不同），會歸為自訂技能，不會自動合併同義詞。
4. **外部 AI 連結無法自動帶入提示詞**：網址長度有限，所以採用「先複製，再開新分頁，請使用者貼上」。部分瀏覽器若擋下新分頁，需要使用者允許。
5. **標記辨識是初步解析**：AI 沒有照格式輸出標記或改寫標記時，會辨識失敗或不完整，需要手動貼入或請 AI 重新輸出。
6. **提示詞只能「要求」AI 遵守**：例如不提 AI 導入、不判定技能程度、不套用獲利模式，實際回覆是否遵守取決於外部 AI，使用者仍需檢查。
7. **展示版自動檢查只是提醒**：關鍵字與格式檢查可能漏判或誤判，最後需使用者逐項確認。
8. **過期提醒只比對工具內的資料**：手動修改過的提示詞文字不會被視為過期。
9. **AI 繪圖的中文字不可靠**：所以預設是留白底圖。
10. **舊版資料轉換**：V1.0.0／V1.0.1 的「專業技能」「熟悉的軟體與工具」是自由文字，轉換時放進「技能補充說明」保留原文，不會自動拆成技能項目；舊版模組 C（企業 AI 應用機會分析）會轉為「AI 應用與流程自動化」主題以維持原意，可自行改為其他主題。
11. **iOS Safari 的下載與列印**：下載的檔案可能直接在新頁面開啟；列印依各瀏覽器的列印對話框運作。
12. **本機儲存的限制**：無痕模式或部分瀏覽器設定可能不允許 LocalStorage，這時會提示改用匯出 JSON 備份。
13. **列印版面較簡單**：以標題和段落排版，不轉換 Markdown 表格；正式 A4 版面規劃在 V1.1。
14. **示範案例與示範 AI 回覆皆為虛構**：只用來體驗操作流程，不代表任何真實企業或人物。
15. **claude.ai 線上預覽版的差異**：預覽版在受限框架中執行，下載會由平台跳出確認；列印改為顯示文字讓使用者複製；開啟外部 AI 的新分頁可能被擋。GitHub Pages 正式版不受影響。
